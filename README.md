# Mens Solution Foundation — Website

A responsive static website for GitHub Pages.

## Included
- Responsive homepage
- Supplied MSF logo, with the organization name updated to "MENS SOLUTION FOUNDATION"
- Programmes and boy-to-man development sections
- Private Room that opens WhatsApp to MSF leadership
- Donation/fundraising section with the supplied Capitec account details
- Copy buttons for account numbers
- Mobile navigation
- No backend required
